# ICCMS Caries Clinical Navigator 🦷

## About The Project
This repository contains the source code for the **ICCMS Caries Clinical Navigator**, an interactive clinical decision support system developed through "Vibe Coding" (Clinician-led, AI-assisted development). 
This tool instantaneously processes patient high-risk determinants and lesion assessments to deliver evidence-based tooth-preserving operative care (TPOC) recommendations.

## Known Issues & Open Source Invitation
As this application was developed by clinical dentists using Large Language Models without formal software engineering training, there may be hidden logic bugs or UI inconsistencies. 
We open-source this code under the MIT License to invite the global dental informatics and developer community to review, fork, and improve upon this prototype.

## How to Run
Simply download the `index.html` file and double-click it to open it in any modern web browser. No backend server or internet connection is required.
